Wildtide: asset prompt library

Prompts for an original 3D creature-collecting RPG, ready to paste into Higgsfield. 161 prompts across 11 sections. All names are working names; change anything.

How to use this

  1. Lock the look. Run the three style tests, pick one image you'd happily ship, and keep it as your golden reference. Attach it to every image prompt after that.
  2. Concept. Generate four variations per asset and pick one. If it doesn't read as a black silhouette, it isn't done.
  3. Model sheet. Attach the pick to the matching turnaround prompt. That sheet is the source of truth.
  4. Mesh. Feed the clean single view into Higgsfield 3D Model (web or the Blender add-on). Check topology, UVs and poly count in Blender before trusting it.
  5. Rig and animate. Try Character Animation in the Blender add-on on humanoids. Test one creature first; four-legged and flying creatures often still need a hand-built rig.
  6. Engine. Put one toon shader on everything. The cel-shaded look should come from the shader, not from light baked into textures. That's what keeps 150 assets looking like one game.
  7. 2D last. Cut icons and UI off their flat backgrounds and rebuild all text in-engine.

Style suffix. It's already baked into every prompt that needs it. Prompts that set their own flat lighting (turnarounds, 3D inputs, textures, icons, UI) leave it out on purpose. If you change the art direction, find and replace this line across the doc:
